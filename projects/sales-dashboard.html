Sales / Business Performance Dashboard

A revenue and profitability dashboard built from the Superstore dataset — tracking regional performance, category-level sales, and where discounting is quietly eroding margin. Built in parallel in Power BI and Excel.

Objective

Give a business stakeholder a single view to answer three questions at a glance: where is revenue coming from, which categories/regions drive profit, and where are discounts hurting more than they help.

Data Source

Dataset: Sample Superstore (public, Kaggle) — 9,994 rows, 13 columns: Ship Mode, Segment, Country, City, State, Postal Code, Region, Category, Sub-Category, Sales, Quantity, Discount, Profit.

QA findings: See Data Integrity Check below for the full audit — duplicates found and flagged, types corrected, and value ranges verified before building any visuals.

Data Integrity Check

A validation pass run on the raw file before any visual was built — every check below was actually executed against the dataset, not assumed.

Removed Duplicate rows: 17 exact duplicate rows found out of 9,994 (0.17%) — removed via Power Query, confirmed at 9,977 rows post-cleaning.
Pass Missing values: 0 nulls across all 13 columns.
Corrected Data types: Postal Code was stored as a number — cast to text to prevent it being summed/averaged by mistake.
Pass Value ranges: Sales $0.44–$22,638.48, Discount 0–80%, Quantity 1–14 — all within plausible bounds, no negative sales or impossible values.
Verified Negative profit rows: 1,871 rows (18.72%) show a loss. Confirmed as genuine — driven by high discounts, not data errors — and kept in for the Profit vs. Discount analysis rather than dropped.
Pass Category consistency: Region (4), Category (3), Segment (3), and Ship Mode (4) values are clean and consistently spelled — no case mismatches or stray variants.
